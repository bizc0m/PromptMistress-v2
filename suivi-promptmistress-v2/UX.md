# PromptMistress V2 — UX

## Principes
- Interface légère, native macOS, sans framework lourd.
- Couleurs sobres : fond `f7f6f3`, encre `#252724`, accent `#365a43`.
- Onglets clairs : Bibliothèque, Fusion/Lab, Importer + legacy plié.

## Navigation
- Header compact avec logo, onglets, état de connexion.
- Bibliothèque : panneau latéral (sources, dossiers, tags) + tableau + inspecteur.
- Importer : 3 étapes (favori, fichier, sélection).

## Comportements
- Les tags favoris apparaissent dans la fiche ; un clic les ajoute.
- Les dossiers virtuels sont créés dans la fiche (champ Dossiers).
- Masquer/Archiver change la visibilité localement.
